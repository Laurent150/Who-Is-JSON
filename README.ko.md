# Who Is JSON

상단의 **解释风格**에서 **零基础友好**(입문자 친화, 기본값)와 **标准**(표준)을 선택할 수 있습니다. 선택은 브라우저에 저장됩니다. 입문자 모드는 현재 코드가 하는 일을 짧은 한두 문장으로 설명하고, 필요할 때만 작은 예를 듭니다. 로컬 자료의 세부 내용은 펼쳐 볼 수 있습니다. 모드를 바꾸면 현재 AI 설명과 설명 원고가 지워지지만 원본 코드와 저장한 카드는 유지됩니다. 사용자가 다시 생성할 때만 AI를 호출합니다. 표현 방식의 지정이 설명의 정확성을 보장하지는 않습니다.

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**찾아온 코드를 이해하고, 그 코드에서 배우세요.**

Who Is JSON은 **vibe coders(AI로 코드를 작성하는 사람)를 위한 AI 코드 읽기 도구**입니다. 소스를 가져와 목적, 처리 단계, 값의 변화를 살펴보고 모르는 용어를 클릭해 설명을 읽을 수 있습니다. 복습이나 면접 준비에 사용할 독립적인 해설문도 생성합니다. 로컬 분석을 지원하는 언어는 원문과 대조하면서 함수, 분기, 반복문을 따라갈 수 있습니다.

**이 한국어판은 문서 번역입니다.** 현재 앱 화면, 기본 지식 카드, AI의 기본 설명은 주로 중국어입니다. 화면 언어 전환은 아직 구현되지 않았습니다. 아래에는 현재 버튼을 찾을 수 있도록 중국어 이름을 함께 표기했습니다. 연결된 참고 문서도 중국어일 수 있습니다.

현재 버전은 **1.0.0 정식 버전(소스 코드 배포)**입니다. [릴리스 노트](docs/releases/v1.0.0.md)를 참고하세요. 코드를 읽고 설명하는 도구이며 가져온 소스를 실행하지 않습니다. 분석 성공이 프로그램의 정상 동작을 보장하지는 않습니다.

이 저장소는 v0.8.0의 공개 배포본입니다. 기존 피드백에서 가져온 테스트 조각은 자체 작성한 예제로 교체했으며, 개발 이력은 원래 비공개 저장소에 남아 있습니다. [공개 이전 안내](docs/PUBLIC_MIGRATION.md)와 [기여자](CONTRIBUTORS.md)를 참고하세요.

## 언어 지원: AI 설명과 구조 탐색은 구분됩니다

**C와 C++도 가져와 AI 설명을 요청할 수 있습니다.** 클릭 설명, 추가 질문, 독립 해설문은 소스를 직접 사용하므로 함수 목록이 없어도 이용할 수 있습니다. 설명 품질은 모델과 제공된 문맥에 따라 달라집니다.

**설명 문장은 AI가 제공하고, 함수 목록·흐름의 뼈대·확인된 호출 위치는 로컬 분석기가 제공합니다.** AI는 기존 노드에 의미를 보충합니다. 로컬 분석기가 없는 언어의 완전한 함수 그래프를 자동으로 만들지는 않습니다.

| 코드 종류 | AI 설명·질문·해설문 | 로컬 구조 |
| --- | --- | --- |
| Python | 요청 가능 | 함수·분기·반복문과 일부 파일 내부 호출 |
| JavaScript / TypeScript, Java, Bash | 요청 가능 | 해당 구조 지원. 복잡한 구문과 호출 관계에는 한계가 있음 |
| Dockerfile, JSON, YAML, HTML, CSS, SQL, `.gitignore` | 요청 가능 | 명령·계층·규칙·문장 등. 모두 프로그램 흐름도로 표시되는 것은 아님 |
| **C / C++** (`.c`, `.cpp`, `.h`) | **가져온 후 AI 설명 요청 가능** | 파일 형식만 식별. 함수 목록·함수 흐름도·호출 펼치기 없음 |
| Go, Rust, C#, PHP, Ruby | 인식하는 확장자를 가져와 AI 설명 요청 가능 | 파일 형식만 식별 |
| MATLAB 등 텍스트 소스 | 붙여넣거나 `.txt`로 가져온 뒤 요청. 필요하면 질문에 언어 명시 | 대응하는 신뢰할 수 있는 로컬 분석기 없음. 모든 원래 확장자를 직접 가져올 수 있는 것은 아님 |

요청 가능은 요청 경로를 제공한다는 뜻이며 모든 언어·구문·모델의 정확성이 검증되었다는 뜻은 아닙니다. C/C++을 컴파일하거나 실행하지 않고, 헤더 구현·외부 라이브러리·프로젝트 전체를 자동으로 읽지도 않습니다.

## 설치

### 필요한 환경

- Node.js: 최소 **20**, CI 환경에 맞춰 **24** 권장. `node`와 함께 설치되는 `npm`을 사용할 수 있어야 합니다.
- Python: 개발 검증 환경과 같은 **3.12** 권장. Windows 개발 스크립트에는 3.12 이상이 필요합니다.
- pnpm: `package.json`의 `packageManager`에 명시된 **10.15.1**.
- 공개 저장소를 복제하거나 GitHub ZIP을 받아 압축을 풉니다.

```sh
git clone https://github.com/Laurent150/Who-Is-JSON-Public.git
cd Who-Is-JSON-Public
```

### Windows (PowerShell 7)

저장소 루트에서 실행합니다.

```powershell
./dev.ps1 -Task Install
./dev.ps1 -Task Start -Python (Get-Command python.exe).Source
```

`Install`은 고정된 pnpm 버전과 잠금 파일에 따른 의존성을 설치합니다. `python.exe`가 Python 3.12가 아니라면 `-Python` 뒤를 Python 3.12 실행 파일 경로로 바꾸세요. 자세한 설정은 [기여 안내](CONTRIBUTING.md)를 참고하세요.

### pnpm이 이미 있는 환경 (Windows / macOS / Linux)

`pnpm --version`이 `10.15.1`인지 확인한 후 실행합니다.

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm start
```

기본 위치에서 Python을 찾을 수 없다면 실행 전에 `CODELINGO_PYTHON`을 설정하세요. macOS / Linux: `export CODELINGO_PYTHON="$(command -v python3)"`. PowerShell: `$env:CODELINGO_PYTHON = (Get-Command python.exe).Source`.

브라우저에서 **http://127.0.0.1:43127**을 엽니다. 터미널의 `Ctrl+C`로 종료하며, 포트는 `CODELINGO_PORT`로 변경합니다. 앱은 로컬 주소에서만 연결을 받습니다. 캡처와 플로팅 창은 Windows 전용입니다. 이번 릴리스는 의존성을 설치해 실행하는 소스 배포이며, 데스크톱 설치 파일을 새로 빌드하지 않았습니다.

## 사용 방법

1. **코드 넣기.** “导入文件”(파일 가져오기), 붙여넣기 또는 “开源代码试读”(오픈 소스 예제)를 사용합니다. 소스는 최대 100 KB이며 원래 파일명이 언어 식별에 도움이 됩니다. 이미지는 “识别代码”(코드 인식) 후 들여쓰기·밑줄·문장부호를 원본과 대조하세요.
2. **작업 공간 열기.** “查看整段结构”(전체 구조 보기)를 누르면 “AI 代码工作台”가 열립니다. 로컬 분석 지원 언어는 함수나 구조 목록을 표시하고, C/C++ 등도 소스는 볼 수 있습니다. 구조 미지원 안내가 AI 설명까지 불가능하다는 의미는 아닙니다.
3. **필요할 때 AI 연결하기.** “设置”(설정)에 Chat Completions 호환 서비스의 기본 URL·모델·키를 입력합니다. 기본 URL은 보통 `/v1`로 끝나며 전체 `/chat/completions` 주소가 아닙니다. 설정을 저장했다고 연결이 검증되는 것은 아닙니다.
4. **코드와 흐름 읽기.** 행을 클릭해 설명을 요청하고 `Shift`로 선택 범위를 넓힙니다. 용어 설명은 `Escape`로 닫습니다. 방향키로 행을 선택하고 오른쪽 키로 용어에 들어갈 수 있습니다. 함수에서 “生成这个函数的 AI 流程”(이 함수의 AI 흐름 생성)을 누른 뒤 단계를 클릭해 소스를 확인하세요. 함수 목록이 없다면 소스 설명이나 해설문을 사용합니다.
5. **복습·면접 준비용 해설문 만들기.** “讲解稿 · 可选”(선택적 해설문)에서 이해 수준·범위·상세도를 정하고 “生成 AI 讲解稿”를 누릅니다. 목적·입출력·전체 접근·주요 단계·예제·한계와 코드별 Q&A를 생성합니다. 형식적인 인사말이나 발표 시간 설정은 없습니다. 먼저 AI 개요나 로컬 함수 목록을 생성할 필요도 없습니다.

“AI 总览（可选）”(선택적 AI 개요)는 분석 시 개요 보충과 이미지의 로컬 OCR / AI 인식을 제어합니다. **흐름 생성, 클릭 설명, 해설문 생성은 별도 AI 작업이며 이 스위치를 꺼도 함께 비활성화되지 않습니다.** 각각 유효한 설정이 필요하고 오류나 재시도 안내가 제공됩니다.

AI를 설정한 상태에서 언어가 불확실하거나 분석에 실패하거나 사용 가능한 프로그램 구조가 없으면 AI가 언어 판별을 돕고 해당 로컬 분석기가 결과를 검증합니다. AI 개요를 선택하지 않아도 동작하며 중지할 수 있습니다. 불확실한 판별, 요청 실패, 로컬 검증 실패 시 원래 결과를 유지합니다. 이 단계에서 소스를 고치거나 구조를 지어내지 않습니다.

복사한 코드에 서식 문제가 있으면 필요에 따라 수정 진입점이 나타납니다. 로컬 정리나 AI 수정 제안을 미리 보고 변경을 확인한 후 적용하세요. 추가 편집 전에는 되돌릴 수 있습니다. AI 수정은 설정한 서비스를 호출하며 소스를 자동 교체하지 않습니다.

### 즐겨찾기와 복습

단순한 이름의 뜻은 설명만 표시합니다. 원리·독립 예제·주의점이 포함된 완전한 지식 카드가 반환될 때만 저장 버튼을 표시합니다. 로딩·연결 안내·오류에는 저장 기능이 없습니다. AI가 내용 종류를 잘못 분류할 수 있으며 예제는 실행하지 않은 가정에 따른 설명입니다.

“我的收藏”(내 즐겨찾기)은 기본적으로 전체 카드를 표시합니다. 문법과 기초, 흐름과 함수, 자료 구조와 알고리즘, 비동기와 오류 처리, 파일·네트워크·시스템, 개발과 설계로 필터링할 수 있습니다. 제목·태그·관련 소스도 검색합니다. 저장된 항목이 있는 분류만 표시하며 카드 분류를 직접 변경할 수 있습니다. 기존 즐겨찾기는 보존하고 주제에 따라 자동 분류합니다. 같은 카드에 여러 소스를 연결할 수 있고, 내보내기에는 분류와 AI 생성 표시가 포함됩니다.

로그인하지 않은 즐겨찾기는 현재 브라우저에 저장됩니다. GitHub로 로그인하면 계정 즐겨찾기와 관련 소스 코드를 클라우드에 동기화할 수 있으며 기존 로컬 즐겨찾기는 자동으로 업로드되지 않습니다. 기본 주소 `http://127.0.0.1:43127/`용 공개 연결 설정이 포함되어 있어 `.env` 설정은 필요하지 않습니다. 네트워크에 따라 클라우드 연결이 실패할 수 있으며 VPN 없이 접속할 수 있다고 보장하지 않습니다. 체험 한도가 남아 있으면 로그인 후 DeepSeek Flash에 자동 연결됩니다. 계정별 한도와 전체 한도가 있으며, 개인 AI 서비스를 직접 설정할 수도 있습니다. [AI 체험 안내](docs/AI_TRIAL.md). [자세한 내용](docs/CLOUD_ACCOUNTS.md).

### C/C++을 읽는 빠른 방법

`.c` / `.cpp` 가져오기 → 전체 구조 보기 → AI 설정 → 행·용어 클릭 또는 해설문 생성. 이 버전에서는 왼쪽에 C/C++ 함수 흐름이 생성되지 않습니다. 헤더·매크로·외부 함수 정의가 빠져 있다면 구체적인 동작 설명을 위해 추가 소스가 필요합니다.

## 입력과 출력 예제

`total.py`로 저장해 가져옵니다.

```python
def total_price(prices):
    total = 0
    for price in prices:
        total += price
    return total

amount = total_price([10, 20])
```

- **구조:** 함수는 1–5행, 반복문은 3–4행이며 7행에서 해당 함수를 호출합니다.
- **목적:** 전달받은 가격들을 더해 합계를 반환합니다.
- **단계:** 합계를 0으로 시작 → 가격을 하나씩 더하기 → 합계 반환.
- **용어:** `[10, 20]`은 두 숫자가 든 리스트입니다. `+=`는 더한 값을 `total`에 다시 저장합니다. `for` 끝의 `:`는 아래 들여쓴 코드가 반복문 본문임을 나타냅니다.
- **가정에 따른 결과:** `0 + 10`, 다음 `10 + 20`으로 `amount`는 30이 됩니다. `print`가 없으므로 30을 출력하지는 않습니다.

위 설명은 의미를 확인하기 위한 예시이며 모델의 고정 출력이 아닙니다. 앱은 이 입력을 실행해 결과를 계산하지 않습니다. AI 설명은 소스와 대조해 판단하세요.

## 데이터와 한계

- 로컬 분석과 로컬 OCR은 모델 서비스에 업로드하지 않습니다. AI 개요·언어 판별·수정·흐름·클릭 설명·해설문은 관련 소스와 선택 내용을 설정한 서비스로 보내며 AI 이미지 인식은 이미지를 보냅니다. 요금과 서버 측 데이터 처리는 해당 서비스에 따릅니다.
- 서비스 주소·모델명·즐겨찾기는 브라우저에 저장합니다. API 키는 영구 저장하지 않으므로 새로고침 후 다시 입력해야 합니다. 즐겨찾기에 소스가 포함될 수 있으니 내보내거나 공유하기 전에 확인하세요.
- OCR은 틀릴 수 있습니다. 들여쓰기는 이미지 위치로 추정하며 분석 가능한 결과라도 원본과 완전히 같다고 보장하지 않습니다.
- 흐름은 로컬에서 인식한 구조에 의존합니다. 현재 파일만으로 외부 함수 내부 동작을 확정할 수 없습니다. 너무 큰 함수는 범위를 줄이도록 안내하며 미완성 AI 노드 설명은 별도로 표시합니다.
- 자동 테스트 통과는 임의의 코드가 정확히 설명되거나 모든 입문자가 이해한다는 보장이 아닙니다. 실제 모델의 품질 평가는 계속 필요합니다. [작업 공간 안내](docs/STUDIO.md)와 [검증 기록](VALIDATION.md)을 참고하세요.
