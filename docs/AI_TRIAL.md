# 平台 AI 试用

每个 GitHub 身份一次性 ¥1 等值试用额度，全平台累计 ¥15 上限；没有自动充值、周期补充或付费订阅。所有账户共享有限总预算，不代表每个账户必然能用完 ¥1。删除 Supabase 用户再注册不会重置同一个 GitHub 身份的额度。多个不同 GitHub 账号无法可靠识别为同一人，总预算负责限制总损失。

## 计量与预算

单位为百万分之一人民币。试用按 DeepSeek Flash 高峰费率折算：每百万输入 token（未命中缓存）¥2，缓存命中 ¥0.04，输出 ¥8，向上舍入到最小单位。来源为 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，核对日期 2026-09-25。低峰期仍按该保守费率消耗赠送额度；它不是现金，不是用户 DeepSeek 账户余额，也不承诺与提供商账单逐分一致。价格变更需先暂停服务并复核，限额不能控制此 API key 在本应用以外的消费。

服务只请求 deepseek-flash，关闭思考，最多 8192 输出 token。只支持文字，图片仍用本地 OCR 或用户自配的视觉服务。输入大小、消息数和模型由云端限制，客户端不能改成更贵的模型。请求前预留输入字节上界与最大输出费用，同时锁定总池和用户钱包；上游返回可信用量后结算实际折算额。单账户最多一笔未结算调用，至少间隔 5 秒。

异常响应、网络中断或进程崩溃可能已产生模型费用，预留额不自动退回；对应请求编号只供管理员核对账单后手工结算，不能让用户领取无限退款。取消本机显示也不保证上游停止计费。新请求不会自动重试。数据库只保存 GitHub 身份号、用量金额和请求编号，不保存提示词或模型答复。

## 部署

1. 执行 `supabase/migrations/202609250001_ai_trial.sql`，默认 `enabled=false`。
2. 执行 `supabase/ai-trial-test.sql`；该验证在事务中回滚，不消耗模型额度。
3. 在 Supabase Edge Functions 部署 `ai-trial`，入口为 `supabase/functions/ai-trial/index.ts`，同时包含 `policy.mjs`。函数显式调用 Auth `/user` 验证用户 JWT 并要求 GitHub 身份；数据库 RPC 仅 service_role 可调用，不能授予匿名或普通用户。
4. 所有者亲自在函数 Secrets 中设置 `DEEPSEEK_API_KEY`，不得放进源码、浏览器、本机发布配置或聊天。`SUPABASE_URL` 和 `SUPABASE_SERVICE_ROLE_KEY` 使用 Edge 环境提供的服务端值。
5. 验证函数鉴权、配额和并发测试后，由所有者批准开启 `who_ai_campaign.enabled`；真实验收消费也计入总池 ¥15。
6. 登录后，未填写自己的 AI 密钥时优先使用平台试用；配置自己的密钥后使用个人服务。试用不可用时明确显示提示，不悄悄向用户个人 API 计费。

平台代付调用会将当前解释所需源码经 Supabase 发送给 DeepSeek。云端网络仍有免费方案的可达性限制。本功能不解决不使用 VPN 时的 Supabase 连接问题。部署完成前不能宣称额度已经发放可用。

界面仅显示 AI 试用可用状态，不显示余额、赠送金额或全平台预算。金额保留在服务端记账和管理员文档中。用户可在设置里断开 AI，或手动切回自己的服务。
