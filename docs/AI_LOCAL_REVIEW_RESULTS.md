# 局部改稿与独立终审对照结果

日期：2026-10-03。对应 [固定方案](AI_LOCAL_REVIEW_EXPERIMENT.md)。

结论：本轮不采用新的局部编辑器替换旧编辑器。独立终审在本批没有表现出额外的硬错误拦截收益，反而增加了一次格式阻断。这个结论仅适用于这批固定旧稿的对照，不能推广为所有代码、模式或模型的能力结论。

## 范围与计数

- 四份保存的候选文字：英文缓存讲解稿、中文库存讲解稿、英文标准语句点读、原本合格的中文入门受众讲解稿。
- 每份旧、新编辑器各重复两次，输入文字与源码一致，调用顺序交替。判断标准在终审前保存；问题标签及参考答案不进入模型输入。
- 16次正常编辑请求，加1次格式修复；其中15份返回有效候选，分别再做一次独立终审。
- 实际32次，低于授权36次上限；旧轮101/104计数独立保留。未调用剩余4次，未启动9例全量复验或新代码验收。
- 所有源码仅做静态分析，没有执行。判定为助手对照源码阅读，不是外部盲评，也不是采用模型自评分。

## 编辑结果

| 指标 | 旧编辑器 | 新局部编辑器 |
| --- | ---: | ---: |
| 尝试结果数 | 8 | 8 |
| 返回有效候选 | 7 | 8 |
| 通过本轮硬错误门槛 | 7 | 6 |
| 候选仍有硬错误 | 0 | 2 |
| 未返回有效正文 | 1 | 0 |
| 新增硬错误 | 0 | 0 |
| 额外格式修复请求 | 0 | 1 |

这是四份文字的重复结果，不能把它当成16段独立新代码的准确率。

明确差异出现在缓存讲解稿。旧版两次都补上了开头和结尾的空值回退条件；新版两次只修开头，保留结尾：

> labelFor itself just returns the stored value on later calls with that key.

源码实际为 `return cache[key] ?? fallback;`。例如缓存里的值被改成null后再次读取，返回的是fallback，不是缓存的null。此处按本轮事先记录的标准属于仍未修复的无条件返回结论；不是新增错误，也不是风格扣分。

库存案例中新版两次都补充了上限比较等前提；旧版一次无正文，一次修复成功。原本合格的中文讲解稿在两种方案中都没有被改坏。英文语句点读中的类型边界措辞按本轮规则不作为硬错误：旧版进行了澄清，新版两次保持原文，没有据此给新版算修复收益。

| 指标 | 数量 |
| --- | ---: |
| 待终审候选 | 15 |
| 有效终审报告 | 14 |
| 模型报告pass | 14 |

| 因终审协议错误阻断本轮合格候选 | 1 |
| 有效reject报告 | 0 |

两份缓存漏改稿都被终审放行。终审理由能正确复述源码的nullish回退规则，却没有指出结尾陈述与规则之间的矛盾。能够复述代码规则，不足以证明逐句核查了最终文字。

一份英文点读候选的终审只返回LOGIC-01、RETURN-01和自造的RETURN-01-note-not-used占位项，遗漏另外6个必查项。程序正确拒绝了不完整报告，但对读者来说仍是一次新增的无结果；它不能被算作成功发现语义错误。

在本批已返回的15份候选中，终审前13份通过本轮门槛；终审后只有12份合格结果能被放行，两份有错结果仍然被放行。这是本批观测，不是长期效果估计。

## 格式与用量

局部编辑的1次格式修复来自源码引用：模型把中间有省略的多段源码拼成一个sourceQuote，导致引用不是原始源码的连续片段。JSON本身有效，引用校验也没有误报。修复后才可应用。这说明增加精确引用约定会产生额外协议负担；不能靠放松校验把它记作原本成功。

旧版1次无正文请求的服务响应标为stop，报告751个输出token，全部计入reasoning_tokens，可见正文为空。记录没有保存隐藏推理内容。能确认可见正文缺失，无法仅凭这条响应确定服务内部原因。

| 模型用量/耗时 | 旧编辑器 | 新局部编辑器 | 独立终审 |
| --- | ---: | ---: | ---: |
| 请求次数 | 8 | 9 | 15 |
| 输入token | 57,538 | 28,125 | 见原始记录 |
| 输出token | 40,013 | 58,035 | 见原始记录 |
| 总token | 97,551 | 86,160 | 143,089 |
| 请求耗时合计 | 168秒 | 257秒 | 328秒 |

新版输入更短，但输出token更多且本批耗时更长；总token减少不能直接等同于费用降低。以上采用服务返回的usage计数，包含失败请求和修复；不是账单金额。全轮合计326,800 token。

## 工程判断和处理

1. 前三步相关文件哈希保持不变，仍只作为控制变量保留，本轮没有证明其单独收益。
2. 新编辑器保持实验状态，不进入正式默认流程。旧版对固定旧稿表现更稳，也不等于原始完整生成链路已验收。
3. 本批不支持把独立终审的pass当成可靠的事实保证。其额外调用价值尚未得到证明；正式默认配置没有在这轮对照中被擅自切换。
4. 按计划停止扩大验收。当前结果不支持直接投入9例、11例控制和未见样本的大轮测试。
5. 如果继续第二轮，应只改变一个变量：保留旧版完整的复核提示与证据，仅切换修改协议，再复验重复漏改和好稿控制。当前试验同时缩短提示并改变修改粒度，不能把失败单独归咎于局部替换机制，更不能用它证明模型能力存在某种不可弥补的差距。第二轮须另行冻结及授权；不循环抽样直到偶然通过。

412项自动测试和19份发布样本检查此前已通过；本轮最终校验确认生产代码和测试计划的冻结哈希未变。程序测试验证的是执行与保护机制，不能抵消本次真实模型的负面质量结果。
