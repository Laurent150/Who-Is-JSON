# 逐行读懂

当前默认入口已升级为 [三列 AI 工作台](STUDIO.md)。下文记录保留的结构与逐行资料视图。

分析后默认打开「流程总览」。有文件顶层准备时先展示该范围，否则提示选择功能，不把第一个函数当作执行入口。点击流程块后在下方展开三栏，保留流程图；步骤范围浅亮，当前语句强亮。在该范围内逐行阅读时保留所属步骤，移到范围外则定位到对应步骤。「返回流程总览」保留当前代码选择。

也可直接切换「逐行读懂」。左栏显示本次分析的完整原文和语法配色；点击一行，中栏解释这条语句，右栏可展开相关名字、关键词和符号。Shift + 点击连续选择，方向键切换行。跨行语句整体选中，外围代码变暗，所属代码块的起始行保留提示。

「流程总览」「逐行读懂」和「讲解稿」可以切换。小屏幕按源码、解释、基础知识的顺序纵向展示。「复制选中语句」保留该范围的原文；如果只分析编辑器中的选区，展示范围也是该分析选区，行号仍对应原文件。

## 本地解释与 AI

默认来自静态解析和规则，不执行源码。Python 新增逐句模型，例如 `total += price` 说明读取原值、加上右值、保存回原变量；`return round(total * discount, 2)` 说明舍入精度和返回结果。规则识别标准内置函数前检查同名覆盖；自定义 `round` 不套用内置舍入解释。数值运算说明标明类型限制，不根据变量名字猜测业务。

点击「用 AI 再讲清楚」才会为当前选区发起补充请求，需要先在设置中配置服务。请求包含本次分析的完整源码和所选行范围，回复标注为 AI 解释。切换选区或修改输入后，旧请求的回复不再显示。原有「使用 AI」分析选项仍保留，两者都属于主动启用的功能。

## 实现与边界

- `line_reading_python.py` 从 Python AST、已有教学模型与源文位置生成 `reading` 单元，包含范围、自然语言说明、基础知识和所属代码块。单次最多生成 350 条语句说明。
- `analyzer.js` 将复制恢复后的单元范围映射回原文，使用一基行号、零基 UTF-16 列号和不含结束列的范围。
- `public/line-reading.js` 负责范围选择和已有知识的整理；其他语言复用已有流程或配置说明，没有新增同等覆盖的语义规则。
- `public/line-reading-ui.js` 负责展示、键盘操作和显式 AI 请求；语法配色用于阅读，不作为语义证据。

本次主要改善 Python 基础语句。未知结构、注释、恢复不完整的源码等可能没有逐句说明，页面会明确提示。没有进行跨文件业务推理，也没有真实初学者理解实验。AI 接口行为同时通过模拟回复与 DeepSeek Flash 实际调用验收；结果仍需对照源码核对，不代表任意输入都能正确解释。

## 验证

使用 Python 3.12，设置 `CODELINGO_PYTHON` 并确保同一解释器也能通过 PATH 上的 `python` 调用。运行 `pnpm test` 和 `pnpm run test:release` 检查源码测试及公开样本。新增 `tests/line-reading.test.js` 覆盖默认参数、循环、返回、内置名称覆盖、同一行多语句、跨行语句、Unicode 与复制行号恢复。

设置 `WHO_PLAYWRIGHT_MODULE` 指向已安装的 Playwright 后，运行 `node tests/browser-line-reading.cjs`。脚本自行启动临时本地服务，通过 Edge 检查默认入口、无入口时选择功能、流程与源码双向定位、步骤与语句两级高亮、返回位置、三栏交互、旧视图切换、AI 设置入口、完整上下文请求、过期回复丢弃及 390px 布局；截图和报告写入 `.browser-artifacts/line-reading`。需要与开发测试相同的 Python 环境。

原有 `tests/browser-semantics.cjs` 继续验证结构视图、源码关联、知识收藏及刷新保留；运行前启动服务并设置 `CODELINGO_URL`。

## AI 等待与结果

开启「AI 辅助分析」后，先显示本地流程，再补充 AI 用途说明；等待区显示已用秒数并支持停止。失败或取消保留本地结果。AI 只补充最多 12 个功能的说明，不替换解析器的功能、行号、流程或基础知识。讲解稿可复用这些说明。逐句 AI 成功后优先展示 AI 回答，本地逐句说明可展开核对。

DeepSeek 官方接口使用非思考模式与有界输出；其他兼容服务不发送 DeepSeek 专有参数。总体说明请求 JSON，追问请求简短纯文本；超时、鉴权、网络权限、DNS 和证书错误分别提示。逐句请求同时携带服务器从原文截取的选中内容，避免模型自行数行。取消会中止本机请求和上游连接，不承诺服务商停止计费。

真实验收需明确授权付费调用。设置 `WHO_AI_KEY_FILE` 为存放测试密钥的本地忽略文件，设置 `CODELINGO_URL` 为正在运行的应用地址及 `WHO_PLAYWRIGHT_MODULE`，运行 `node tests/browser-ai-live.cjs`。测试会向 DeepSeek 发送公开二分查找样本和自编教学图片；报告不保存密钥。`tests/browser-ai-states.cjs` 使用模拟回复验证取消、失败与输入变化，不调用远程模型。
