# FIMI v1.2.0 · Windows 发布候选

本版本准备发布，安装包签名与最终发布状态以 Release 附件和验证记录为准。

- 更名 FIMI，保留旧版安装路径以支持覆盖升级；中英文界面及语言切换。
- 结构信息归入代码工作台；已连接AI时按选择生成步骤和输入/输出说明。
- 函数、步骤、行和词语点读，解释收藏及原源码回看；解释不写回输入。
- 三种讲解受众：入门理解、同事交流、代码评审。默认采用先生成函数约定、再对照源码撰稿的两阶段链路，使用已抽查的双语提示。
- 安装器和启动器版本与应用版本一致，明确打包新增模块。左侧悬浮入口默认隐藏，兼容代码保留。

## 下载与升级

Windows 10/11 x64 下载 FIMI-1.2.0-Windows-x64-Setup.exe。安装包含Node.js/Python，按当前用户权限运行。Source code并非安装包。内部WhoIsJSON.exe、注册键和旧目录保留，界面名称为FIMI。卸载保留用户额外文件和日志；不同浏览器本地收藏不会自动迁移。

当前候选未签名，仍可能有Windows或浏览器信任提示。不要将本地安装通过说成安全提示已解决；参见[安装排查](../WINDOWS_INSTALL.md)。SHA256SUMS.txt用于核对下载完整性，不替代签名。

## 内容抽查与边界

五份自编留出源码、中英文共10份实际稿，7份经人工核对通过；另有一次额度不足失败保留，共11次尝试。已知剩余错误涉及异常恢复范围、标题重试计数及引用共享影响范围。十份格式有效，五份英文稿未见无关中文。这不是任意代码准确率保证，也不是所有模型的质量承诺。

AI将所选源码发送至配置的服务，不执行输入。外部依赖实现缺失时不能保证其行为。云登录和试用需要网络及可用额度，未扩大试用预算。安装、升级、卸载与本地自测的本次结果见VALIDATION.md；跨设备、全Windows环境及有效签名仍需单独核验。
