# FIMI v1.2.1 · Windows 发布候选

本版本整合已选定的代码讲解方案、CloudBase 邮箱账户与试用服务，以及桌面外观和导出改进。安装包先生成草稿 Release，最终发布状态以 Release 页面为准。

## 本版变化

- 零基础单词点读采用角色优先的短卡片：先说明变量、参数、函数等角色，再解释当前用途；中英文分别适配。暂时关闭此入口的 AI 复核与终审，只保留一次生成及本地格式检查。
- 标准单词点读保留简短初稿和复核，取消独立终审；零基础行读、段读保留方法3和已选段落复核。
- 讲解稿采用已选定的非技术方法4、同事交流方法2、代码评审融合成稿，保留各自已选复核，取消独立终审。代码评审使用较高输出额度，保留异常消耗与截断保护。
- CloudBase 邮箱登录、收藏同步和有限 AI 试用；改进请求诊断、额度查询失败提示及恢复入口。个人 AI 配置仍可独立使用。
- 中英文工作台、解释收藏与源码定位、Word/Markdown 导出；统一 FIMI 图标、英文首次界面和桌面窗口设置。
- 修复 JSON 模式提示兼容和部分格式交付问题；保留取消、错误提示与源码范围检查，不执行用户代码。

## 验证与限制

当前源码通过517项自动测试和19份公开样本检查；这不等于任意代码的解释准确率，也不等于所有提示都已完成最新真实模型复测。历史真实对照和已知局限保留于 VALIDATION.md。最新零基础短卡片仍需用户实际体验确认。

Windows 安装、升级、卸载及自测由本次安装工作流单独验证，以对应构建报告为准。安装包未具备有效商业签名时，仍可能出现 Windows 信任提示。云端可用性依赖网络、部署配置与额度，合并源码不会自动部署 CloudBase 服务。

## 安装与升级

下载 `FIMI-1.2.1-Windows-x64-Setup.exe`，配合 `SHA256SUMS.txt` 核对文件。支持 Windows 10/11 x64，包含 Node.js 与 Python，按当前用户安装。内部可执行文件名与旧版安装标识保留，以支持覆盖升级。卸载保留用户额外文件和日志；不同浏览器的本地收藏不会自动迁移。
