# FIMI v1.2.2 - Windows Desktop

Improved code reading, email trial access, and workspace usability, with an English Windows x64 installer.

## Changes

- Reading cards open below the selected word, symbol, or line. Drag their title to move them, scroll long explanations, and close them with the close button. Clicking elsewhere keeps the card open. Repeated reads reuse completed answers within the current page.
- Restored CloudBase email trial access and quota queries. Trial and regular official DeepSeek Flash connections share the same word, line, passage, and module reading rules. Confirmed cloud-side generation or parsing failures refund the associated trial charge.
- Removed Simplify. Examples and questions about the current source file use one short generation; unrelated questions are declined with a helpful prompt.
- First launch defaults to English. An explicitly selected language is remembered. Unsigned sessions open the sign-in dialog, and local mode has a clear notice.
- Unified dark green inline code styling, refined workspace spacing, and removed preview badges, AI overview, and redundant help text. The walkthrough feature is temporarily unavailable.
- Installer, uninstaller, desktop launcher messages, Start menu shortcuts, and the bundled installation guide use English.

## Install or upgrade

Download `FIMI-1.2.2-Windows-x64-Setup.exe` and verify it against `SHA256SUMS.txt`. Supports Windows 10/11 x64, installs for the current user, and includes Node.js and Python.

The installer is not code-signed (NotSigned). Windows may display an unknown publisher warning.

Bookmarks stay in the browser you use and do not automatically transfer between browsers. Uninstalling preserves extra user files and logs.

## Validation and limitations

- 627 automated tests, 19 release samples, and 12 reading-card browser checks passed. Browser checks used mock responses and made no paid AI calls.
- The installed runtime, shortcuts, upgrade from 1.2.1, repeat installation, and safe uninstall are checked separately from source tests.
- The updated CloudBase generation and refund protocols are deployed. A real account previously confirmed quota access and successful trial reading.
- New source and installer contents are checked for credentials and personal information. Local settings, sessions, diagnostic logs, and screenshots are excluded. Required third-party attributions are retained. Historical Git metadata is outside this release's privacy cleanup scope.
- Refunds rely on trusted cloud failure records. An uncertain delivery after successful generation still requires verification. Source relevance checks cannot detect every disguised request, and AI explanations should be checked against the source.

README files are unchanged in this release. See VALIDATION.md for engineering records.
