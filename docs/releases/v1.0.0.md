# Who Is JSON v1.0.0

面向 vibe coders 的第一版 AI 代码阅读工具。本次为正式源码发布，不包含新构建或验收的 Windows EXE 安装包。1.0 表示当前功能范围的首个正式版本，不代表 AI 解释不会出错。

## 主要功能

- 导入、粘贴源码，在三列工作台查看函数流程、原文和当前步骤解释；支持词语点读、追问与独立讲解稿。
- 零基础友好 / 标准两种解释风格，浏览器记住选择；切换清除旧解释，保留源码、配置和收藏。
- 知识卡分类收藏、搜索与导出；收藏保存在本地浏览器。
- 本地解析与可选 AI 辅助识别、复制格式修复预览及撤销。导入源码不被执行。
- 更清晰的取消、超时、失败反馈；保留本地结构与源码位置。
- 整理顶部标语、左侧收藏/悬浮窗/设置入口和选择框；提供中、英、日、韩 README。界面语言切换尚未实现。

## 安装

1. 下载本 Release 的 Source code ZIP，或克隆仓库并切换到 `v1.0.0`。
2. 准备 Node.js 24、Python 3.12、pnpm 10.15.1。
3. 运行 `pnpm install --frozen-lockfile --ignore-scripts`，按需设置 `CODELINGO_PYTHON`，然后 `pnpm start`。
4. 打开 `http://127.0.0.1:43127/`。AI 功能需在设置中填写自己的兼容服务地址、模型及密钥。

Windows 辅助启动方法见 [README](../../README.md)。本版本不包含用户登录、云端收藏同步或由项目方统一支付 AI 费用。

## 验证与已知限制

- 发布前运行自动测试和19份公开样本校验，具体记录见 [VALIDATION](../../VALIDATION.md)。已进行实际页面布局、导入、解释模式与复杂源码的真实 DeepSeek 抽查；未完成新的安装包和真人新手理解实验。
- **AI 解释仍可能出错。** 已发现复杂共享请求的取消逻辑在重复回答中不稳定，也可能省略错误分支或使用较多术语。请对照源码，不将解释直接作为生产变更的正确性证明。
- 一次小范围事实复核试验纠正了两份相反样本中的错误，但没有证明稳定可靠，因此本版未添加自动二次复核，不额外增加一轮调用费用与等待。
- 本地结构支持深度因语言而异；C/C++等代码可以请求AI解释，但没有完整本地函数流程解析。OCR结果需要核对。
- 密钥仅保留在当前页面内存，刷新需重填；配置显示不表示连接已验证。使用AI会将本次源码及选中内容发送给配置的服务，费用由使用者承担。
- 收藏只在当前浏览器保存，清理浏览器数据可能丢失，建议导出备份。

上述模型质量问题作为1.0已知限制公开保留，不声称已经彻底修复。许可及第三方数据来源沿用项目现有说明。
