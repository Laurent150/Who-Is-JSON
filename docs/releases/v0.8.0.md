# v0.8.0 · AI 代码工作台、源码点读与讲解稿

这是一个预览版源码发布，汇总已经合并的工作台功能与使用说明。产品面向希望看懂别人或 AI 写出的代码，并从中学习的用户。

## 本次发布内容

- 迁入已有功能：三列 AI 代码工作台、流程与源码联动、点读词语及独立 AI 讲解稿。
- 迁入文档与维护改进：按当前功能重写 README，补齐安装、使用、输入输出示例和数据发送说明；忽略本地仓库检查报告。
- 应用版本与页面显示统一为 0.8.0，补充发布说明并整理文档入口。

本次没有新增一轮解析器或教学规则改写，不将已有功能重新描述成新的准确率提升。

## 当前功能

| 功能 | 当前可以做什么 |
| --- | --- |
| 导入源码 | 粘贴、拖入或选择源码文件；支持分析整个文件或选定范围，源码上限 100 KB |
| 三列工作台 | 左边按函数展开流程，中间对照原文，右边显示当前步骤的解释和例子 |
| 流程关联 | 展开条件、循环、异常路径和已确认的本文件函数调用；点节点定位源码，递归有停止展开提示 |
| 源码点读 | 选择语句，或点击变量、函数名、关键词、运算符，获取与当前上下文相关的 AI 解释 |
| 本地学习资料 | 在结构资料中阅读已有语法知识和示例，收藏、导出学习内容 |
| 独立讲解稿 | 按阅读基础、讲解范围和详略生成 AI 稿件，支持停止、重试、导出和专注讲稿 |
| 图片识别 | 内置英文、简体中文 OCR；也可使用支持图片的 AI 服务，识别后核对原图再分析 |
| Windows 辅助工具 | 保留框选截图和桌面悬浮窗入口 |

本地解析覆盖 Python、JS/TS、Java、Bash、Dockerfile、JSON、YAML、HTML、CSS、SQL 和 `.gitignore`，各语言的解释深度不同。当前没有可靠的 C、C++、MATLAB 本地解析支持。

## 安装和开始使用

1. 下载本 Release 的 Source code ZIP 或克隆仓库。
2. 准备 Node.js 24、Python 3.12 和 pnpm 10.15.1。
3. 运行 `pnpm install --frozen-lockfile --ignore-scripts`，配置 Python 后运行 `pnpm start`。Windows 的自动安装入口见根目录 README。
4. 打开 `http://127.0.0.1:43127`，导入代码并点击“查看整段结构”。
5. 使用 AI 流程、点读或讲解稿前，在设置中填写自己的兼容服务配置。

完整步骤、输入输出示例与平台差异见 [README](../../README.md)。本次提供源码，不包含新的 EXE 安装包。

## 验证与限制

- 207 项自动测试、19 份公开代码样本检查通过；样本检查包含字节哈希和结构定位。
- Edge 工作台与讲解稿的模拟 AI 浏览器检查通过，涵盖流程联动、词语弹窗、缓存、取消、过期回复、导出和移动布局。
- Windows / Ubuntu 的仓库 CI 在对应发布 PR 中运行，结果以 GitHub 检查记录为准。
- 真实模型对最新工作台与讲解稿的解释质量仍未完成验收；没有进行零基础用户理解实验或新安装包验收。因此标记为预览版。
- 本地分析不执行导入的代码。本地 OCR 仍可能识错字符和缩进，必须对照原图。
- 工作台中的 AI 操作会将本次源码和选择范围发送到配置的模型服务；AI 识图发送图片。不能仅凭当前文件确认外部函数的内部行为。
