# Who Is JSON v1.1.0 · Windows 桌面版

## 下载与安装

Windows 10 / 11 64 位用户下载 **Who-Is-JSON-1.1.0-Windows-x64-Setup.exe**，安装后双击桌面图标使用。程序自带 Node.js 24.19.0、Python 3.12.10、解析依赖和本地 OCR 数据，无需另装开发环境。`Source code` 是供开发者使用的源码包。

安装采用当前用户权限，提供桌面与开始菜单快捷方式及卸载入口。界面使用 Edge 独立窗口，没有 Edge 时使用默认浏览器。关闭窗口后后台服务仍在托盘运行，可从托盘菜单退出。安装包未作商业代码签名，Windows 可能显示未知发布者；本页同时提供 SHA256SUMS.txt 校验文件。

## 本版功能

- GitHub 登录、账户收藏云同步；本地收藏不会未经选择自动上传。
- 平台 AI 试用可用时，登录后默认接入 DeepSeek Flash；可取消试用回到本地模式，也可配置自己的服务。试用有个人和全平台限额，耗尽或停用后不再代付。
- 保留 AI 代码工作台、源码点读、流程框图、结构资料与独立讲解稿。
- 精简首页和账户操作，保留购物车示例、源码拖入、图片粘贴及桌面悬浮窗功能。

## 验证与限制

安装包发布流程检查源码测试与公开样本，并在隔离目录验证安装文件哈希、桌面/开始菜单快捷方式、自带 Python 解析、公共登录配置、覆盖升级与卸载保留用户文件。安装包检查不调用付费模型。

免费 Supabase 云服务需要网络可达，可能不稳定；不保证所有地区关闭 VPN 后仍能登录或同步。本地解析和本地收藏不依赖云端。GitHub 登录和真实 AI 试用此前在可达网络验证通过；本版没有扩大代付额度。会话保存在服务内存，重启后需重新登录。

AI 会将本次分析的源码发送给所用服务，解释可能出错，需要对照源码。应用不执行导入代码；OCR 结果需核对。卸载保留浏览器收藏及用户额外文件，不会自动迁移不同浏览器的本地收藏。尚未完成所有 Windows 环境、多显示器截图及两台真实设备同步验收。
