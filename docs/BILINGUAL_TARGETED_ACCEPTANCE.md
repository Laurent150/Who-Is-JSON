## 已观察到的改善

- Requests 的 `is not None` 不再把替换旧值解释成保留旧值；Java 区间交集取较大下界和较小上界。
- Python 队列的协程、取消条件及唤醒目标得到修正；JavaScript 流程使用选中的内部函数，正常返回不再被说成必须等待 Promise。
- 时长分解例子现在将 90000 毫秒解释为 1 分 30 秒、余数 0 毫秒；原长度失败的总览已能返回。
- Java 接口的六个静态／默认／抽象方法均进入总览；主要函数不会再被 import 抢占解释名额。
- Zod 英文稿已区分“工厂返回异步函数”和“调用这个异步函数得到 Promise”，也保留了编译校验的快速路径。
- 时区稿保留了显式参数优先级以及减去较小偏移的表达，没有复现原来相反的时间方向例子。

以上是选定事实点的复核结果，不是整份答案或全部 26 条历史发现的关闭证明。

## 修正内容

- Java 接口的静态、默认、抽象方法进入函数目录；抽象声明不生成虚构的函数体流程。
- AI 总览优先选择主要函数，保留原始索引，展示覆盖数量；最多 12 个块，不宣称覆盖全部函数。
- 总览块、流程节点和词语选区附带准确的源码片段，减少模型自行数行或套用相邻函数的风险。节点缺少说明时明确提示。
- 中英文增加事实及教学复核，检查条件正反、边界、数据更新和语言差异。结构化响应只申请修改需要修正的文字字段，提供允许的准确路径，不允许通过补丁修改节点编号、源码位置或新增路径。零基础问答在复核前即清空，避免要求模型修改被禁止的数组；深层流程说明可修改，但节点身份仍保持不变。
- 英文补充 Python 协程与 JavaScript Promise 的区别。零基础讲解稿不自动追加问题；复核要求先讲具体动作和结果，并解释必要术语。
- 英文错误信息和流程展开／收起文案已补齐；新复核错误也有英文提示。增加两阶段请求的等待时间，并防止已取消的请求继续启动复核。
- 讲解稿输出预算兼容现有平台试用接口的 8192 上限。未改变账户赠送额度或全平台费用上限。
